# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good intent, and keep discussions about the work. Report concerns to the maintainers in
`.github/CODEOWNERS`; reports are handled confidentially.

One addition for AI-assisted work: submitting code you have not read or understood, or hiding AI involvement,
is treated as a violation of the collaboration norms in `CONTRIBUTING.md`.
