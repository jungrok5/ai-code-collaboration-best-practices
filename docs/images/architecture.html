규칙

모든 도구가 읽음. 강제력 없음

  • AGENTS.md 하나가 단일 원본(약 60줄)
  • 도구별 파일은 이 파일을 가리키기만 함
  • 경로별 규칙: 워크플로, 테스트, 글과 화면
2

개발자 PC에서 차단

AI가 규칙을 잊어도 사고가 나지 않게

  • 훅: 비밀·정책 파일 수정, main 커밋, 강제 푸시
  • 수정 직후 포맷과 글·화면 기준 검사
  • pre-commit: 사람의 커밋에도 같은 검사
3

GitHub 서버에서 차단

어떤 도구로 만든 코드든 마지막 관문

  • 룰셋: PR 필수, CODEOWNER 승인, ci-ok, squash만
  • 이슈·PR 양식과 AI 사용 공개
  • CodeQL, 비밀 스캔, Dependabot
5

AI가 실행되는 곳

내 자리 (기본)내 claude 로그인, 키 없음
사내 로컬 LLMAI_BACKEND=local
AnthropicAI_BACKEND=anthropic
