팀 작업 보드: work-board가 30분마다 모든 레포의 활성 설계와 열린 PR 파일을 board.json으로 모아 세션 시작 요약에 넣습니다. design-check는 PR 겹침을 댓글로 알립니다(LLM 없음, 차단 없음).

CI가 실패하면 ci-fix가 로그를 읽고 수정 PR을 엽니다. @claude 댓글로 질문하거나 수정을 요청할 수 있습니다. 주간 유지보수 리포트, stale 정리, Dependabot 자동 머지(minor/patch).
