# ADR-0006: 하네스를 최신 모델 기준으로 덜어내기

- 상태: Accepted
- 날짜: 2026-10-08

## 맥락

규칙·스킬·훅·권한이 지시를 덜 따르던 모델을 기준으로 쓰여 있었어요. 지금 모델은 지시를 강하게 따르므로 강조 문구와 중복 규칙이 과잉 반응과 토큰 비용을 낳아요(Anthropic 가이드, ETH Zurich AGENTS.md 연구). 넓은 `ask` 목록은 auto 모드에서도 매번 확인을 띄웠어요.

## 결정

- 결정적 안전장치(보호 경로, `main` 커밋·force-push 차단, CI, CODEOWNERS, 룰셋)는 유지해요.
- 800줄 커밋 차단 훅과 Stop 리마인더 훅을 없애고, 스킬에는 목표와 제약만 남겨요. AGENTS.md는 명령어와 레포 특유의 함정 위주로 줄여요.
- 권한은 auto 모드로 두고 `ask`에는 `rm -r(f)`만 남겨요. 되돌리기 어려운 것(기본 브랜치 push, PR 머지)은 `deny`로 막아요.
- 모델을 올릴 때마다 `docs/15-lean-harness.md` §4 점검을 해요.

## 결과

- 긍정: 확인 프롬프트 감소, 컨텍스트 축소, 규칙 충돌 감소.
- 부정: 규칙이 줄어 새 모델의 약점이 드러날 수 있음 → 반복되는 실수에만 한 줄씩 추가.
