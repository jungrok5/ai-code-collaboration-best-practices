# ADR 0008: 시각적 설명을 기본 팀 스킬로 제공합니다

- Status: Proposed
- Date: 2026-10-12

## Context

사용자는 작업 흐름을 따라가는 설명 페이지를 확인한 뒤 같은 방식을 기본 팀 스킬과 저장소의 안내 페이지로 요청했습니다.
기존 상세 문서는 설정과 워크플로 정보를 충분히 담고 있지만 처음 읽을 때 핵심 구조를 파악하기 어렵습니다.

## Decision

`explain-visually`를 기본 플러그인 `team-ai-workflow`에 포함하고 버전을 1.7.0으로 갱신합니다. 원문을 읽고 핵심 한 문장,
대표 작업, 검사 지점, 사람 판단, 실패 시 복귀 경로를 그림과 단계별 설명으로 구성합니다. 한 줄 답변에는 호출하지 않습니다.

메인 페이지는 확인된 Draw.io 설명 방식으로 교체하고, 기존 해설을 `guide.html`, 전체 지도를 `map.html`로 유지합니다.
Next AI Draw.io의 검증 모듈을 사용하며 정적 SVG 렌더러와 화면 런타임은 팀 코드로 구분합니다. 편집기는 고정한 npm
패키지에서 Pages 빌드 시 가져오므로 대용량 외부 자산을 저장소에 커밋하지 않습니다.

## Verification

SVG 네임스페이스, 노드와 연결선, 단계 이동, 노드 선택, 모바일 너비에서 실제 배율 변화와 전체보기 후 스크롤 초기화를
검사합니다. 기본 스킬에는 사용·미사용 평가 케이스를 둡니다. 브라우저·실기기 검증과 사람 CODEOWNER 승인은 별도입니다.
