# team-ai-community

팀원이 기여한 선택 설치용 스킬 모음입니다. 기본 플러그인(`team-ai-workflow`)보다 검토 기준이 가볍습니다.

```bash
claude plugin install team-ai-community@ai-collab   # 필요한 사람만 설치
```

스킬 추가 절차와 승격 기준은 [docs/18-adding-skills.md](../../docs/18-adding-skills.md)에 있습니다. 새 스킬은
`make new-skill NAME=<이름> TIER=community`로 만듭니다.
