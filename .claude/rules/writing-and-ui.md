# Writing and UI

Text people read and UI people use follow `docs/17-writing-and-design-standards.md`: use the `polish-writing` skill
for prose and copy, `polish-ui` for markup and styles.
UI uses the repo's design tokens, or the team default "Clear" when the repo has none (docs/17 §2-1). After each edit the style check reports AI-tone and AI-look
patterns; fix the errors, judge the warnings. Never add facts or numbers while polishing.
